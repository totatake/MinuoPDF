========================================
ソフトウェア要件仕様書 (Requirements)
========================================

本ドキュメントは、MinuoPDF アプリケーションの機能要件および非機能要件を定義します。

機能要件 (Functional Requirements)
======================================

GUI 共通およびウィンドウ管理
-----------------------------

.. req:: ウィンドウ表示サイズと柔軟なリサイズ制御
   :id: REQ_GUI_001
   :status: open

   GUI起動時、初期ウィンドウサイズは幅 740px、高さ 560px で表示されること。また、画面表示を崩さず幅広い解像度に対応するため、最小サイズ制約（幅 680px、高さ 520px）を保持しつつリサイズ可能（``resizable: true``）であること。

.. req:: 多言語切り替え (日本語 / 英語)
   :id: REQ_GUI_002
   :status: open

   画面右上の言語切り替えボタンにより、GUI上の表示テキスト（ツールチップ、メッセージログ、エラー警告等を含む）が「日本語(JA)」と「English(EN)」で動的に切り替わること。

.. req:: バルーンヘルプ (ツールチップ) 表示
   :id: REQ_GUI_003
   :status: open

   詳細モード内の主要コントロールにホバーした際、機能説明と容量・画質への影響を示すツールチップが表示されること。

.. req:: 処理進捗・ステータス表示
   :id: REQ_GUI_004
   :status: open

   圧縮実行時、リアルタイムに処理進捗率（0-100%）、プログレスバー、および処理中のファイル名が表示されること。

.. req:: 実行コンソールログ
   :id: REQ_GUI_005
   :status: open

   圧縮完了時、コンソールログエリアに処理結果（圧縮成功/失敗、変換前後の容量、容量削減率）が表示されること。

対象ファイルリスト管理
-----------------------

.. req:: ドラッグ＆ドロップによるファイル追加
   :id: REQ_FILE_001
   :status: open

   アプリケーション画面（特にドロップエリア）へのドラッグ＆ドロップにより、PDFファイルをリストに追加できること。PDF以外の拡張子は除外されること。

.. req:: ファイル選択ダイアログによる追加
   :id: REQ_FILE_002
   :status: open

   「PDF追加...」ボタンからOS標準のファイル選択ダイアログを開き、複数ファイルを選択してリストに追加できること。

.. req:: リスト要素の個別削除および全クリア
   :id: REQ_FILE_003
   :status: open

   選択したファイルの個別削除および「すべてクリア」ボタンによる一括削除ができること。

プリセットおよびプロファイル管理
---------------------------------

.. req:: 圧縮プリセットの選択
   :id: REQ_PROF_001
   :status: open

   簡単モードにおいて、高画質・標準・軽量化・白黒化・強制画像化の5つの基本プリセットから1つを選択でき、説明テキストが連動表示されること。

.. req:: カスタム設定プロファイルの保存・復元・削除
   :id: REQ_PROF_002
   :status: open

   詳細設定を任意の名前で JSON プロファイルとして実行ファイル同階層の ``profiles/`` ディレクトリに保存・読み込み・削除できること。プロファイルのバージョン検証（v2以降）が行われること。

最適化コア機能
---------------

.. req:: カラー変換モード
   :id: REQ_OPT_001
   :status: open

   Color (JPEG再圧縮)、Gray (グレースケール変換)、Mono (白黒二値化 + CCITT Group 4 圧縮) のカラーモードを選択できること。

.. req:: モノクロ二値化アルゴリズム
   :id: REQ_OPT_002
   :status: open

   Mono モードにおいて、「大津の二値化 (Otsu)」または「誤差拡散ディザリング (Floyd-Steinberg)」を選択できること。

.. req:: 解像度(DPI)とJPEG品質調整
   :id: REQ_OPT_003
   :status: open

   リサイズ目標DPI（50, 72, 100, 150, 200, 300, 450）および JPEG 圧縮品質（10～100%）を設定できること。

.. req:: 圧縮戦略の切替 (テキスト保持 / 完全ラスタライズ)
   :id: REQ_OPT_004
   :status: open

   既存テキストデータやレイアウトを保持して画像オブジェクトのみを差替える「テキスト保持モード」と、ページ全体を画像として再描画する「完全ラスタライズモード」を切り替えられること。

.. req:: 不要オブジェクトの破棄
   :id: REQ_OPT_005
   :status: open

   注釈・コメント、リンク、しおり目次、AcroFormフォーム、XMLメタデータ、JavaScript/OpenAction、サムネイル画像を物理的に破棄できること。

.. req:: フォントサブセット化および埋め込み解除 (Unembed Fonts)
   :id: REQ_OPT_006
   :status: open

   使用文字のみのフォントサブセット化、および指定フォントの埋め込みストリームを削除して標準代替フォントに切り替えさせるフォント解除が実行できること。

.. req:: 逆圧縮防止ガード (Smart Fallback)
   :id: REQ_OPT_007
   :status: open

   リサイズやカラーモード変換を伴わない画像において、再エンコード後のバイトサイズが元ストリームのサイズを上回る（逆圧縮・容量肥大化）場合、自動的に元ストリームを維持して品質劣化と容量増大を防止すること。

.. req:: CTM実効DPI算出・Form XObject走査・SMask連動
   :id: REQ_OPT_008
   :status: open

   コンテンツストリームの現在変換行列（CTM）および描画オペレータを解析してページ上での実効表示サイズ（pt）に基づく正確なDPI推定を行うこと。また、Form XObject（/Subtype /Form）内のネストされた埋め込み画像を再帰走査し、親画像のリサイズ時には透過マスク（SMask）も同一比率に連動リサイズすること。

.. req:: PDF容量内訳解析 (PDF Audit)
   :id: REQ_AUDIT_001
   :status: open

   PDF内の全オブジェクトを走査し、Images, Fonts, Content Streams, Metadata/Catalog, Struct/Forms, Other のカテゴリ別にバイト数と構成比率（%）を算出・可視化できること。最適化完了時には変換前後の内訳比較を提供すること。

CUI モード (コマンドライン)
---------------------------

.. req:: コマンドライン対話モード
   :id: REQ_CLI_001
   :status: open

   コマンドライン引数に対象PDFを単一指定して起動した場合、GUIを表示せずに対話形式のコンソールメニューにより圧縮条件を設定・実行できること。

.. req:: 非対話バッチCLIモード
   :id: REQ_CLI_002
   :status: open

   CLI引数オプション（``-o/--output``, ``-p/--preset``, ``--profile``, ``-s/--strategy``, ``-b/--batch`` 等）を指定することで、プロンプト入力なしでスクリプトやCI/CDからヘッドレス実行できること。


非機能要件 (Non-Functional Requirements)
========================================

.. req:: マルチコア並列処理とインメモリパイプライン
   :id: REQ_PERF_001
   :status: open

   Rayon を用いて画像デコード・リサイズ・エンコードをマルチスレッド並列処理すること。また、最適化処理と容量監査処理の間で同一のインメモリ Document オブジェクトを再利用し、余分なディスクI/Oおよび構文解析オーバーヘッドを排除すること。

.. req:: 完全非GPLライセンス
   :id: REQ_NFR_001
   :status: open

   すべての依存クレートおよびライブラリは MIT, BSD, Apache-2.0 等のオープンかつ非GPLライセンスに準拠すること。

.. req:: ポータビリティ (ポータブル動作)
   :id: REQ_NFR_002
   :status: open

   インストーラ不要で単体動作し、設定ファイルやプロファイルはすべて実行ファイルと同一ディレクトリ内で完結すること。

.. req:: Windowsコンソール隠蔽制御
   :id: REQ_NFR_003
   :status: open

   GUI起動時、Win32 API を用いて背面の黒いプロンプト画面を動的に非表示化すること。
