## 2. 機能要件 (Functional Requirements)

### 2.1 GUI 共通およびウィンドウ管理

#### `REQ_GUI_001`: ウィンドウ表示サイズと柔軟なリサイズ制御
GUI 起動時、初期ウィンドウサイズは幅 740px、高さ 560px で表示されること。また、画面表示を崩さず幅広い解像度に対応するため、最小サイズ制約（幅 680px、高さ 520px）を保持しつつリサイズ可能（`resizable: true`）であること。

#### `REQ_GUI_002`: 多言語自動判定・切り替え (Auto / 日本語 / 英語)
初期状態は `auto`（OS / ブラウザロケール `navigator.languages` / `navigator.language` が `ja*` なら日本語、それ以外は英語）で自動判定し、画面右上の言語選択コントロールから `auto`・`日本語 (JA)`・`English (EN)` を選択することで GUI 上の表示テキスト（ツールチップ、メッセージログ、エラー警告等を含む）が動的に切り替わること。

#### `REQ_GUI_003`: バルーンヘルプ (ツールチップ) 表示
詳細モード内の主要コントロールにホバーした際、機能説明と容量・画質への影響を示すツールチップが表示されること。

#### `REQ_GUI_004`: 処理進捗・ステータス表示
圧縮実行時、リアルタイムに処理進捗率（0-100%）、プログレスバー、および処理中のファイル名が表示されること。

#### `REQ_GUI_005`: 実行コンソールログ
圧縮完了時、コンソールログエリアに処理結果（圧縮成功/失敗、変換前後の容量、容量削減率）が表示されること。

### 2.2 対象ファイルリスト管理

#### `REQ_FILE_001`: ドラッグ＆ドロップによるファイル追加
アプリケーション画面（特にドロップエリア）へのドラッグ＆ドロップにより、PDF ファイルをリストに追加できること。PDF 以外の拡張子は除外されること。

#### `REQ_FILE_002`: ファイル選択ダイアログによる追加
「PDF追加...」ボタンから OS 標準のファイル選択ダイアログを開き、複数ファイルを選択してリストに追加できること。

#### `REQ_FILE_003`: リスト要素の個別削除および全クリア
選択したファイルの個別削除および「すべてクリア」ボタンによる一括削除ができること。

### 2.3 プリセットおよびプロファイル管理

#### `REQ_PROF_001`: 圧縮プリセットの選択
簡単モードにおいて、高画質・標準・軽量化・白黒化・強制画像化の 5 つの基本プリセットから 1 つを選択でき、説明テキストが連動表示されること。

#### `REQ_PROF_002`: カスタム設定プロファイルの保存・復元・削除
詳細設定を任意の名前で JSON プロファイルとして実行ファイル同階層の `profiles/` ディレクトリに保存・読み込み・削除できること。プロファイルのバージョン検証（v2 以降）が行われること。

### 2.4 最適化コア機能

#### `REQ_OPT_001`: カラー変換モード
Color（JPEG 再圧縮）、Gray（グレースケール変換）、Mono（白黒二値化 + CCITT Group 4 圧縮）のカラーモードを選択できること。

#### `REQ_OPT_002`: モノクロ二値化アルゴリズム
Mono モードにおいて、「大津の二値化 (Otsu)」または「誤差拡散ディザリング (Floyd-Steinberg)」を選択できること。

#### `REQ_OPT_003`: 解像度 (DPI) と JPEG 品質調整
リサイズ目標 DPI（50, 72, 100, 150, 200, 300, 450）および JPEG 圧縮品質（10〜100%）を設定できること。

#### `REQ_OPT_004`: 圧縮戦略の切替 (テキスト保持 / 完全ラスタライズ)
既存テキストデータやレイアウトを保持して画像オブジェクトのみを差替える「テキスト保持モード」と、ページ全体を画像として再描画する「完全ラスタライズモード」を切り替えられること。

#### `REQ_OPT_005`: 不要オブジェクトの破棄
注釈・コメント、リンク、しおり目次、AcroForm フォーム、XML メタデータ、JavaScript/OpenAction、サムネイル画像を物理的に破棄できること。

#### `REQ_OPT_006`: フォントサブセット化および埋め込み解除 (Unembed Fonts)
使用文字のみのフォントサブセット化、および指定フォントの埋め込みストリームを削除して標準代替フォントに切り替えさせるフォント解除が実行できること。

#### `REQ_OPT_007`: 逆圧縮防止ガード (Smart Fallback)
リサイズやカラーモード変換を伴わない画像において、再エンコード後のバイトサイズが元ストリームのサイズを上回る（逆圧縮・容量肥大化）場合、自動的に元ストリームを維持して品質劣化と容量増大を防止すること。

#### `REQ_OPT_008`: CTM 実効 DPI 算出・Form XObject 走査・SMask 連動
コンテンツストリームの現在変換行列（CTM）および描画オペレータを解析してページ上での実効表示サイズ（pt）に基づく正確な DPI 推定を行うこと。また、Form XObject（`/Subtype /Form`）内のネストされた埋め込み画像を再帰走査し、親画像のリサイズ時には透過マスク（SMask）も同一比率に連動リサイズすること。

#### `REQ_AUDIT_001`: PDF 容量内訳解析 (PDF Audit)
PDF 内の全オブジェクトを走査し、Images, Fonts, Content Streams, Metadata/Catalog, Struct/Forms, Other のカテゴリ別にバイト数と構成比率（%）を算出・可視化できること。最適化完了時には変換前後の内訳比較を提供すること。

### 2.5 CUI モード (コマンドライン)

#### `REQ_CLI_001`: コマンドライン対話モード
コマンドライン引数に対象 PDF を単一指定して起動した場合、GUI を表示せずに対話形式のコンソールメニューにより圧縮条件を設定・実行できること。

#### `REQ_CLI_002`: 非対話バッチ CLI モード
CLI 引数オプション（`-o/--output`, `-p/--preset`, `--profile`, `-s/--strategy`, `-b/--batch` 等）を指定することで、プロンプト入力なしでスクリプトや CI/CD からヘッドレス実行できること。

## 3. 非機能要件 (Non-Functional Requirements)

#### `REQ_PERF_001`: マルチコア並列処理とインメモリパイプライン
Rayon を用いて画像デコード・リサイズ・エンコードをマルチスレッド並列処理すること。また、最適化処理と容量監査処理の間で同一のインメモリ Document オブジェクトを再利用し、余分なディスク I/O および構文解析オーバーヘッドを排除すること。

#### `REQ_NFR_001`: 完全非 GPL ライセンス
すべての依存クレートおよびライブラリは MIT, BSD, Apache-2.0 等のオープンかつ非 GPL ライセンスに準拠すること。

#### `REQ_NFR_002`: ポータビリティ (ポータブル動作)
インストーラ不要で単体動作し、設定ファイルやプロファイルはすべて実行ファイルと同一ディレクトリ内で完結すること。

#### `REQ_NFR_003`: Windows コンソール隠蔽制御
GUI 起動時、Win32 API を用いて背面の黒いプロンプト画面を動的に非表示化すること。
