========================================
MinuoPDF ドキュメントへようこそ
========================================

**MinuoPDF** は、PDFの閲覧品質を維持しつつファイルサイズを極限まで軽量化する、非GPL（MIT/BSD準拠）かつ完全ポータブルなPDF最適化ツールです。
デスクトップGUI（Tauri v2 + Svelte 5）と高速対話型CUI（Rust）の両モードを提供します。

プロジェクト概要
==================

- **超軽量・ポータブル性**: インストーラ不要、同一フォルダ内の ``pdfium.dll`` を自動自動ロード。
- **完全非GPLライセンス**: 商用利用・社内閉域環境でも安心して利用可能な MIT / Apache 2.0 構成。
- **多様な最適化機能**: JPEG再圧縮、白黒二値化（大津の二値化 / ディザリング）、テキスト保持/完全ラスタライズ切替、不要オブジェクト破棄、フォントサブセット化・埋め込み解除。
